Lamello P-System CNC Toolpath Addin

NatureBoy Carpentry — Fusion Manufacture add-in for Lamello P-System (Clamex P) connector toolpaths.

Install

  1. Install with the Autodesk App Store installer for your platform (Windows or Mac).
  2. Start Fusion. If the add-in is not already running, open Utilities → Add-Ins, select LamelloPSystemCNC, and click Run.
  3. Switch to the Manufacture workspace. The command is pinned on the ADD-INS toolbar (overflow menu if unpinned).

First use

  1. Open a design with placement points (Joint Origins, sketch points, vertices, or construction points).
  2. Ensure at least one milling Setup exists (with WCS defined). If the document tool library is empty, the add-in offers to install bundled Lamello sample tools; you can also use Add sample tools on the Setup tab later.
  3. Run Lamello P-System CNC Toolpath Addin.
  4. On the Setup tab, choose the setup and Edge / Face / Drill tools. Expand each tool’s parameters group to edit feeds and speeds if needed.
  5. On the Edge tab, add placement sets: select anchor points, the planar cut-in face, and connector type (P14 / P10). On the Face tab, use a linear feed axis instead. Adjust Flip feed / Flip Z and optional Edge drill options as needed.
  6. Use Preview to inspect live preview sketches under the Clamex Toolpaths component.
  7. Click OK to generate Trace (and optional Drill) operations for the active milling tab only.

What it creates

  • A root-level component named Clamex Toolpaths (stable name; re-runs replace existing geometry).
  • Edge: feed-path sketches and Trace ops; optional Drill ops for key holes.
  • Face: cavity-path sketches and Trace ops.

Troubleshooting

  • No tools found: choose Yes when prompted to install sample tools, or use Add sample tools on the Setup tab after adding your own tools.
  • No CAM setups found: create a milling Setup with WCS, then re-run.
  • Command not visible: ensure the add-in is running and you are in Manufacture.
  • Preview missing: enable Preview, then check the Clamex Toolpaths component light bulb.
  • Grey OK / incomplete sets: OK stays disabled until the active tab has at least one valid set (anchors + cut-in face on Edge, or anchors + feed axis on Face), plus Setup and that tab’s tool on the Setup tab.
